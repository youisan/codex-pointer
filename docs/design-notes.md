# 0.2.0 界面与验证

用户方向：与当前 Codex 客户端风格协调，简约、可随时调用，并有克制的动效。

视觉依据来自本机客户端样式中的灰阶、字级与圆角定义；只采用这些设计取值，没有复制客户端图片、字体或品牌标志。布局参考由内置 Image Gen 生成，保存在 [design-direction.png](design-direction.png)。生成 brief：460px 原生紧凑浮层、同布局深浅主题、目标行、新建/继续切换、任务输入、截图工具栏和单个主按钮；黑白灰，细边框、小阴影，避免营销大标题和鲜艳装饰。

实现为原生 PySide6 组件。预览来自真实组件的 `QWidget.grab()` 离屏渲染，未捕获用户桌面。浏览器无法验证本次原生窗口，因此使用 Qt 离屏交互检查；这不代表完成了所有真实桌面环境的视觉验收。

| 检查点 | 视觉基准与实现 |
| --- | --- |
| 布局 | 默认单个紧凑面板，约 488 × 465（含 14px 阴影边距）；继续模式按需展示绑定行 |
| 配色 | 浅色白底 / #f9f9f9 表面 / #181818 主文字；深色 #181818 底 / #212121 表面 / #ededed 文字 |
| 字体 | Segoe UI 和系统中文字体，正文 14px、辅助 12px、产品名称 16px，路径截断可悬停查看 |
| 轮廓 | 20px 面板圆角、细分隔线、柔和阴影、胶囊主按钮，细线矢量图标风格统一 |
| 内容 | 保留目标、新建/继续、任务、截图和一个主操作；诊断与技术元数据移入菜单 |
| 状态 | 空任务主按钮禁用；文件夹无窗口时禁用截图；预填与发送显示不同结果，不暗示任务已完成 |
| 动态 | 160ms 弹层淡入 / 轻移、140ms 悬停与按压、处理细环、短暂完成标记；系统及手动减少动画有效 |

有意的状态差异：概念图显示可用主按钮，实际空任务显示禁用态；示例为文件夹，所以截图入口禁用。产品名称使用本地系统字体，没有分发客户端字体。未增加概念图之外的首页文案或营销模块。

已检查新建入口不会直接发送、已有对话明确绑定、关闭后保留草稿、深浅主题切换、局部截图严格裁剪且隐藏本程序窗口、减少动画和弹层边界。真实软件控制、共享发送服务及多显示器混合 DPI 的完整链路仍需更多环境验证。

对照结果：[浅色](preview-light.png)、[深色](preview-dark.png)。布局、排版、配色、轮廓和主要文案已按视觉基准逐项检查；离屏环境没有观察到主操作裁切或意外换行。
