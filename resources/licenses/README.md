# License text provenance

These are unmodified license texts from the official Qt source mirror at the
same tag used by this application's Qt runtime. They are redistributed as
license notices; the Codex Pointer project's MIT license does not replace them.

- `LGPL-3.0.txt`: https://raw.githubusercontent.com/qt/qtbase/v6.7.0/LICENSES/LGPL-3.0-only.txt
- `GPL-3.0.txt`: https://raw.githubusercontent.com/qt/qtbase/v6.7.0/LICENSES/GPL-3.0-only.txt

`scripts/build.ps1` copies these texts and available installed package license
files into the release, and generates `THIRD_PARTY_NOTICES.txt` with runtime
versions, original source locations, and library replacement instructions.
